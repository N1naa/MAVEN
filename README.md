# MAVEN
Author: Nina Bodenstab
Reason: Master thesis
Date: 03.03.2026 - 04.06.2026
Github for motion-activated closed-loop transcutaneous auricular vagus nerve stimulation for stroke rehabilitation research project.

# Folders
BNO085 folder contains the code for python, C++, and front-end languages for interfacing, saving, and streaming from the BNO085-ESP32C6 configurations
Xsens_dot folder contains the code for interfacing, streaming, and saving with the Movella Xsens Dots
